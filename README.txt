
# Bike Sharing Demand Analysis

## 1. Project Overview

This project analyzes hourly bike-sharing demand in Washington, D.C., using the UCI Bike Sharing Dataset.

The main research question is:

**How do time of day, weather conditions, and temperature relate to bike-sharing demand?**

The goal is to explore patterns in bike rentals through data analysis and visualization.

## 2. Dataset Source

The dataset is available from the UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

The main dataset used in this project is `hour.csv`, which contains 17,379 hourly observations and 17 columns.

Important variables include:

- `hr`: Hour of the day
- `weathersit`: Weather situation
- `temp`: Normalized temperature
- `hum`: Normalized humidity
- `windspeed`: Normalized wind speed
- `cnt`: Total number of bike rentals

The dataset is used for educational and analytical purposes. Please refer to the original dataset page for its licensing and attribution requirements.

## 3. Methods and Tools

The analysis was conducted using Python and Jupyter Notebook.

Libraries used:

- Pandas: Data loading and data manipulation
- NumPy: Numerical computing
- Matplotlib: Data visualization
- Seaborn: Statistical data visualization

The analysis includes:

1. Loading and inspecting the dataset.
2. Checking data types and missing values.
3. Calculating descriptive statistics.
4. Comparing average bike rentals across hours of the day.
5. Comparing average bike rentals across weather situations.
6. Exploring the relationship between normalized temperature and rental counts.

## 4. Key Findings

### Hourly Demand

The hourly demand visualization shows that bike-sharing usage varies throughout the day. Rental demand tends to be higher during morning and evening commuting periods than during many overnight hours.

### Weather Conditions

The weather comparison indicates that rental demand differs across weather situations. Clearer weather generally corresponds to higher average rental counts than less favorable weather conditions.

### Temperature and Demand

The scatter plot helps explore the relationship between normalized temperature and rental counts. The overall pattern suggests that temperature is associated with rental demand, although individual observations vary considerably.

## 5. Limitations

This analysis is exploratory and describes associations rather than causal relationships. Other factors, such as season, working days, holidays, and user behavior, may also influence rental demand.

In addition, `temp` is normalized temperature rather than a value expressed directly in degrees Celsius.

## 7. How to Run the Analysis

### Prerequisites

Install Python and Jupyter Notebook.

### Step 1: Obtain the Project Files

Download or clone this repository. Ensure that `hour.csv`, the notebook, and `requirements.txt` are available in the project directory.

### Step 2: Install Dependencies

Run the following command in a terminal:

```bash
pip install -r requirements.txt
```

### Step 3: Open the Notebook

Open `bike_sharing_analysis.ipynb` in Jupyter Notebook.

### Step 4: Run the Analysis

Execute the notebook cells in order. The notebook reads `hour.csv`, performs the analysis, and generates the visualizations.

The `images` directory is created automatically by the image-saving code if it does not already exist.
